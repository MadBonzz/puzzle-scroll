# Original content and rights record

This record covers only the currently released generator families and quick-check fixtures. It is not a legal opinion and does not clear any external dataset listed in docs/audit/dataset-source-catalog.md.

## Original generators

The prompts, rules, options, explanations, and generator code identified by source ID 'puzzlescroll-original' or 'puzzlescroll-original-check-v1' are authored in this repository. No third-party question-bank wording was copied into the released catalog during this implementation. Their production publication metadata links to this section.

Automated correctness checks do not constitute human editorial review or timing calibration. Those statuses remain separate.

## Public-domain classic adaptations

The following families use uncopyrightable mathematical facts or long-established puzzle mechanics, with newly written wording, values, options, and explanations in this repository:

- 'equation-system': solving two simultaneous linear equations.
- 'ratio-puzzle': partitioning a total by a stated ratio.
- 'weighing-puzzle': balance-scale deduction using an explicitly stated heavy-object premise.
- 'seating-deduction': finite ordering under stated constraints.
- 'cryptic-clue': an original clue instance using anagram mechanics.

No text from the Wall Street Quants ebook or another external question bank was imported. Before any future external pack is staged, its manifest must document the actual content license or owner permission; a repository's code license alone is insufficient.
